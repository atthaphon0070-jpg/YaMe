# YaMe’ ญาเม่ Sleeping Mask — สไลด์นำเสนอรอบ 20 เดือน

ไฟล์ `index.html` เป็นสไลด์นำเสนอ 12 หน้า (16:9) แบบไฟล์เดียว: ฟอนต์ รูปภาพ CSS และ JavaScript ฝังอยู่ในไฟล์ทั้งหมด
ดับเบิลคลิกเปิดด้วย Chrome ได้ทันทีโดยไม่ต้องต่ออินเทอร์เน็ต

## การควบคุม

| การกระทำ | ปุ่ม |
|---|---|

เปิดที่สไลด์ที่ต้องการได้ด้วย `index.html#7`

## ไฟล์ PDF

`YaMe-Sleeping-Mask-Presentation.pdf` มีเนื้อหาเดียวกับ `index.html`: 12 หน้า หน้าละ 1 สไลด์ ขนาด 16:9
แอนิเมชันทั้งหมดแสดงในสภาพสุดท้าย ส่วนที่ใช้โต้ตอบได้ (แถบควบคุม ไอคอนธงที่ต้อง hover และแผงตรวจสอบ) ไม่อยู่ใน PDF
ข้อความใน PDF เลือกและค้นหาได้ เพราะฝังฟอนต์ไว้แล้ว

ถ้าแก้ `index.html` แล้วต้องการ PDF ใหม่ ให้เปิดไฟล์ใน Chrome แล้วกด `Ctrl+P` จากนั้นเลือก Destination เป็น “Save as PDF” และตั้ง Margins เป็น None
ขนาดหน้าและพื้นหลังถูกกำหนดไว้ในไฟล์แล้ว ไฟล์ที่ได้จะใหญ่กว่าไฟล์ PDF ใน repo เพราะไม่ได้ผ่านขั้นบีบอัดภาพ

## ข้อมูลใน PDF ที่ต้องยืนยัน

สไลด์คงตัวเลขและข้อความตาม PDF ต้นฉบับ รายการด้านล่างแสดงไว้ในแผง ⚑ ของสไลด์ด้วย

1. **กำไรสุทธิปี 2569:** การ์ดสรุประบุ 13,800 บาท แต่กราฟระบุ 23,240 บาท (185,920 − 162,680 = 23,240)
2. **ช่วงเวลาของยอดปี 2569:** ไม่ได้ระบุว่าเป็นยอดสะสมของเดือนใดถึงเดือนใด
3. **อัตรากำไรปี 2568:** ประมาณ 29.9% ต่างจากปี 2569 ซึ่งอยู่ที่ 12.5% (ตรงกับราคา 320 / ต้นทุน 280)
4. **ใบรับรองเกษตรอินทรีย์:** ออกให้แหล่งผลิตพืชอินทรีย์ ไม่ใช่ตัวผลิตภัณฑ์ และระบุวันหมดอายุ 8 ธ.ค. 2566
5. **เครื่องหมายการค้า:** PDF มีเพียงงานออกแบบ ไม่มีเอกสารการจดทะเบียน
6. **ชื่อผลิตภัณฑ์สะกดไม่ตรงกัน:** “สลีปปิ้งมาสก์” / “สลีปปิ้งมาร์ค” / “สลีปปิ้งมาร์ก” และในระบบ อย. เป็น “สลิปปิ้ง มาร์ค (SLEEPING MARK)”
7. **แบบสอบถาม:** ไม่ระบุจำนวนผู้ตอบ และไม่ระบุสเกลของคะแนนเฉลี่ย 3.67
8. **ภาพหน้า 6:** ภาพสปาดูเป็นภาพประกอบ ควรยืนยันว่าเป็นภาพจากการทดสอบจริงหรือไม่
9. **ภาพผู้ประกอบการ:** มีภาพบุคคล 1 ภาพ แต่มีชื่อผู้เข้ารับการบ่มเพาะ 2 คน
10. **ลำดับหัวข้อ “สิ่งที่ได้เรียนรู้”:** PDF ข้ามข้อ 3 สไลด์จึงจัดลำดับใหม่เป็น 01–05
